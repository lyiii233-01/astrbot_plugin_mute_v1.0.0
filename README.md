# 闭嘴插件

让机器人闭嘴一段时间，时间可手动调整。

## 用法

| 方式 | 效果 |
| --- | --- |
| `/mute 10` | 闭嘴 10 秒 |
| `/mute` | 闭嘴，时长用默认值 |
| `/mute 0` | 立刻解除 |
| `/unmute` | 提前解除 |
| `/mute_status` | 看还剩多少秒 |
| 说「别说话」「闭嘴」 | 按默认时长闭嘴（群聊需 @ 或喊到） |
| 闭嘴期间说「可以说话了」 | 立刻解除 |

## 说明

- 闭嘴按会话隔离，私聊和各个群互不影响。
- 闭嘴期间不发回复、不调用模型；`/` 开头的指令仍然可以用，方便提前解除。
- 默认时长、上限、触发关键词、确认文案都能在插件配置页改。
